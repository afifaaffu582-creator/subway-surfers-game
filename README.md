# Metro Dash Runner

A student-friendly endless runner game inspired by the lane-based runner genre. It uses original emoji-based visuals and is not affiliated with Subway Surfers.

## Features
- Three lanes and keyboard controls
- Jumping, obstacles, and collectible coins
- Score and coin counters
- Game-over and restart screen
- Responsive browser layout

## Run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Click **Start Game**.
4. Use Left/Right or A/D to move. Press Space or Up to jump.
